Execution results now cross one configurable byte admission boundary before either the in-process
result cache or the execution store can retain them. Oversized and unconvertible outputs produce a
typed, content-free terminal answer consistently with or without persistence, and rejection metrics
carry only the fixed payload-state label. The existing graph payload limit applies in no-store mode,
while a durable adapter may tighten it. Cached results retain canonical immutable bytes, so later
mutation of an engine result or a prior read cannot change the recorded answer.
