Ravenroot now stores the exact canonical GraphML document behind every accepted execution, so a server that restarts or hands ownership to another process recovers the graph from durable storage instead of asking the caller to submit it again. The document is stored before the execution that references it, and acceptance is refused if it cannot be stored, so an accepted execution is always one whose graph can be produced again. Stored documents are verified against their digest on every read and are scoped to a single tenant; identical documents submitted repeatedly within a tenant are stored once, and distinct documents are never confused with one another. Documents are held alongside execution state, so an existing backup captures both and a restore returns them together. Reclaiming unreferenced documents is an operator action and cannot remove one that a retained execution still names.
