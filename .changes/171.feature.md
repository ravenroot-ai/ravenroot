Ravenroot now provides a policy-driven publication boundary guard that checks an exact typed candidate
against a digest-pinned, operator-owned profile before an external effect. Declarative rules cover
destinations, logical paths, sensitive content, languages, artifact types, required file pairs, and
provenance while fixed violation results and audit evidence omit candidate values. Provider adapters
must re-evaluate the exact candidate immediately before publishing; the guard does not grant network,
credential, storage, or provider authority.
