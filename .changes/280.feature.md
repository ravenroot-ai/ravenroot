**Multi-release JDBC driver jars.** The JDBC extension now loads the multi-release driver jars that
current vendors publish, including PostgreSQL JDBC 42.7.12. Each jar is still verified against its
pinned SHA-256, then resolved once, for Java 21, into the single flat image the driver is defined
from, whatever JVM runs Ravenroot. A jar whose versioned entries can be read in more than one way is
refused before the driver initializes, as `JDBC_DRIVER_AMBIGUOUS`.
