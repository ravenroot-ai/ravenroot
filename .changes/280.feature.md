**Multi-release JDBC driver jars.** The JDBC extension now loads the multi-release driver jars that
current vendors publish, so a bundle can use PostgreSQL JDBC 42.7.12 and the security fixes released
since the vendor moved to that packaging. Each jar is still verified against its pinned SHA-256, then
resolved once, for the release Ravenroot targets, into the single flat image the driver is defined
from, whatever JVM runs Ravenroot. A jar that admits more than one reading of what its image contains
is refused before the driver initializes, as `JDBC_DRIVER_AMBIGUOUS`; bytes that do not match the
pinned digest are refused as before. Driver jars that carry no versioned entries load unchanged.
