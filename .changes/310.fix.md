A pull request into `dev` no longer triggers CI directly. That trigger had regressed to publishing
the required `ci-required` check from a small diagnostic tier, without the full test suite ever
running on the pull request's head. The review candidate is now verified by one dispatched full run
before its pull request opens, by the merge queue once it is queued, and — for a routed Dependabot
dependency update — by the same full run before it can reach `dev`. The fast feedback workflow for
work-branch pushes keeps the cheap checks the retired tier used to run, so contributors still see
that signal on every push.
