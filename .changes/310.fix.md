Verification now happens upstream, on the work branch. A push to a `feature/**` branch runs a fast
feedback workflow; the full functional suite runs on a dispatched review candidate, on pull requests
into `dev`, and on merge-group commits once a merge queue is enabled. The `dev` to `main` promotion
carries only the security gate and the two checks that keep the release classification coherent. The
`ci-required` gate no longer reports success when a job the event required was skipped, removed, or
silently re-gated, checks the tier against the event independently of the classifier, and can be
published only by a full-tier run — which previously allowed a pull request to be green without
having run the suite that would have caught its regression. The end-to-end suite runs across parallel
shards so the added verification does not lengthen the review cycle.
