**PostgreSQL JDBC driver 42.7.7.** This release ships the driver at 42.7.7, used by the PostgreSQL
persistence module (`ravenroot-persistence-postgresql`) and the JDBC extension (`ravenroot-jdbc`).
That version is affected by CVE-2026-54291 and CVE-2026-42198. The release was made knowingly with
both; the driver upgrade ships in the next release (#336).
