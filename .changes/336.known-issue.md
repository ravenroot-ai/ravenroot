**PostgreSQL JDBC driver 42.7.7.** This release ships the PostgreSQL JDBC driver at 42.7.7 as a
runtime dependency of the PostgreSQL persistence module (`ravenroot-persistence-postgresql`), which
`ravenroot-server` includes. That version is affected by CVE-2026-54291 and CVE-2026-42198. The
release was made knowingly with both; the driver upgrade ships in the next release (#336). The JDBC
extension (`ravenroot-jdbc`) ships no driver: operators supply their own when they build its bundle,
and should use a fixed driver version rather than the 42.7.7 artifact in the JDBC bundle reference
example.
