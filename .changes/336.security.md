The PostgreSQL shared execution store now ships PostgreSQL JDBC 42.7.12, which fixes a silent
channel-binding authentication downgrade (GHSA-j92g-9f8w-j867, CVE-2026-54291) and a CPU-exhaustion
denial of service through unbounded PBKDF2 iterations in SCRAM authentication (GHSA-98qh-xjc8-98pq,
CVE-2026-42198). Deployments that select the shared store receive the corrected driver without
configuration changes.
