Explicit Workspace lifecycle nodes and named Agents replace the generic workspace-agent node.
Workspace scope and container reuse are independent, with durable cancellation, pool scheduling,
operator-sized capacities and supervised workers. A separate PostgreSQL-backed runner coordinator
can scale independently of workers; the full graph/authoring server remains single replica.
Upgrade requires stopping writers, applying SQLite migration 30 or PostgreSQL migration 10, and
replacing old generic graph nodes with a Workspace plus Agents using typed workspaceRef. Ordinary
Agent graphs are unchanged. Writable model-backed execution requires an approved model profile,
Landlock-capable Linux and positively verified storage quotas; unsupported hosts fail closed.
