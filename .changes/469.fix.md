The Monitoring graph now settles. Once node movement is no longer visually significant the layout stops
and holds a stable view, instead of drifting through a long tail of imperceptible force motion. A
runtime instance-count change still resizes the node and updates its collision size for the next
layout, but no longer reheats or restarts an already settled graph, so live activity no longer keeps
the view in motion. Dragging a node still reheats the layout so it can adjust around the new position
and then settle again, and explicit layout and force-control changes continue to reheat as before.
