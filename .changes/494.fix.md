Launching a Test or Run no longer re-renders the Monitoring graph. The previous run's colours, instance
counts and edge activity are cleared in place on the graph already on screen, so node positions and the
zoom/pan view stay exactly where they were instead of the layout re-arranging itself on every launch; a
cleared graph shows the same idle node size a freshly opened Monitoring view does. Dragging a node,
arranging the layout explicitly, and the repulsion/attraction/speed controls still reheat the graph.
