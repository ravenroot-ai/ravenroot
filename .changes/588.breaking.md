Managed graph links retain repository identity and revision, and the editor offers a searchable, paginated source picker. Creating a successor draft is now explicit through the provider-neutral versions API or a confirmed editor action: release makes the authored version immutable independently of publication. Clients that previously relied on automatic save-time advancement must create vN+1 first; subsequent saves and content restores retain its assigned version. Back up legacy divergent vN work before explicitly reconciling and reapplying it to a successor. Publication and deployment remain separate. Reopening an already-open managed source preserves unsaved work and refreshes clean sources in place; workspace restoration protects unsaved managed changes and repository scope.
