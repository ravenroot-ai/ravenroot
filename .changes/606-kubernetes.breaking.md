Kubernetes pools now require Kubernetes 1.34 or newer, `PodLevelResources` enabled consistently on the API server, scheduler and every kubelet, a 100 ms CFS quota period, and approved CPU ceilings of at least 20m. Enable these prerequisites before starting managers. The approved Pod CPU request and limit and all memory budgets remain unchanged; the Agent container's CPU request and limit are now 80% of the approved ceiling, rounded down to an integer millicore. Preflight rejects missing or changed resource budgets and requires fresh positive own-container CPU-throttling evidence within ten seconds; ancestor counters and elapsed time cannot substitute for that proof.
