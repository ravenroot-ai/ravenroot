Ravenroot publishes an accepted architecture contract for controlling a deployment's lifecycle
remotely: eight commands — start, pause, resume, drain, stop, undeploy, cancel and restart — each
answered by one of nine typed outcomes rather than by an exception, with an operator's decision
pinned to the exact lifecycle generation it was made against so a command that arrives after someone
else has acted is reported as stale instead of silently overwriting the newer decision. A deployment
now distinguishes being paused from being drained, and a client-chosen idempotency key covers the
generation, so retrying the same words after the lifecycle moved is reported as a conflict rather
than replayed as if it had been applied. No externally published contract changes in this release:
the HTTP routes, CLI verbs and OpenAPI document keep exactly their current behavior, and no command
in this vocabulary is accepted by a running service yet.
