# Get started

Install Ravenroot, validate one GraphML document, and complete a first Test and Run.

## Reading path

- [Install and start Ravenroot](install-start.md) — Choose a supported launch path, start on loopback, and verify liveness, readiness, runtime, and node discovery.
- [Build your first graph](first-graph.md) — Create or import the minimal START–BEHAVIOR–END graph and validate its executable structure.
- [Test, run, and inspect](first-execution.md) — Compare side-effect-free Test with effectful Run, then read terminal evidence and events.

## Authority boundary

The guided path keeps the first graph local and non-privileged until the reader deliberately selects Run; exact validation and execution behavior stays in Reference.
