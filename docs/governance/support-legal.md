# Support, security disclosure, and legal

Use public support for reproducible product questions and a private security channel for suspected vulnerabilities or sensitive incident evidence.

## Required practice

- A support report includes release, launch topology, selected engine, sanitized configuration, command or endpoint, expected response, actual classified error, and minimal non-sensitive GraphML.
- A security report includes affected boundary, preconditions, impact, reproducible steps, and safe contact details; do not publish tokens, credentials, personal data, or exploit material.
- Operational incidents preserve timestamps, execution IDs, event cursors, and audit identifiers while redacting payload and secret values.
