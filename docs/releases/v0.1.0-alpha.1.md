# Ravenroot 0.1.0-alpha.1

This is Ravenroot's first public alpha: a graph-governed actor-model runtime for building embedded
Java applications and standalone services from reviewed GraphML definitions.

Highlights include the public application and node SDK, Pekko execution engine, durable SQLite
execution state, server and CLI surfaces, browser workspace, optional integration extensions,
container deployment assets, and security boundaries for identity, credentials, programmable
artifacts, persistence, and operator-provided isolation.

Alpha compatibility may evolve before 1.0. Review the compatibility policy and operator guides
before production use, pin every Maven and OCI dependency to this exact version, and use an immutable
container digest where deployment reproducibility matters.
