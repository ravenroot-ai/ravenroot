# Ravenroot 0.2.1-alpha.1

Ravenroot 0.2.1-alpha.1 delivers the work integrated since `0.2.0-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Known issues

- **PostgreSQL JDBC driver 42.7.7.** This release ships the PostgreSQL JDBC driver at 42.7.7 as a
  runtime dependency of the PostgreSQL persistence module (`ravenroot-persistence-postgresql`), which
  `ravenroot-server` includes. That version is affected by CVE-2026-54291 (GHSA-j92g-9f8w-j867) and
  CVE-2026-42198 (GHSA-98qh-xjc8-98pq). The release was made knowingly with both; the driver upgrade to
  42.7.12 ships in the next release (#336). The JDBC extension (`ravenroot-jdbc`) ships no driver:
  operators supply their own when they build its bundle. Its driver loader does not yet accept
  multi-release driver jars, which includes PostgreSQL JDBC 42.7.12, so a bundle cannot use the fixed
  driver until that limitation is lifted (#280).

## Fixes

- Verification now happens upstream, on the work branch. A push to a `feature/**` branch runs a fast
  feedback workflow; the full functional suite runs on a dispatched review candidate, on pull requests
  into `dev`, and on merge-group commits once a merge queue is enabled. The `ci-required` gate no longer
  reports success when a job the event required was skipped, removed, or silently re-gated — which
  previously allowed a pull request to be green without having run the suite that would have caught its
  regression — and it checks the tier against the event independently of the classifier. The
  `dev` to `main` promotion carries only the security gate and the release-coherence checks, is granted
  to the internal `dev` branch alone, and is green only when a complete run on `dev` has already passed on the
  exact promoted commit. Commits that carry assistant attribution are refused. The end-to-end suite
  runs across parallel shards so the added verification does not lengthen the review cycle.
- Human Tasks now remain durable pending boundaries in parallel graph traversals: completed sibling
  leaves no longer complete the traversal early, and arrivals at all-branches joins survive restart and
  combine with the settled Human Task outcome exactly once.
- Release publication now bundles, for every Maven Central artifact, the exact file Maven signed and the
  signature written beside it. `0.2.0-alpha.1` was tagged but never published: its release stopped
  before any external write because the bundle looked for the distribution POM's signature under a
  name the build does not produce. The GitHub release zip is now the same file Maven Central receives.
