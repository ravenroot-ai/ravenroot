# Ravenroot 0.3.1-alpha.1

Ravenroot 0.3.1-alpha.1 delivers the work integrated since `0.3.0-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Known issues

- **The JDBC extension cannot yet load the fixed PostgreSQL driver.** The extension (`ravenroot-jdbc`)
  ships no driver: operators supply their own when they build its bundle. Its driver loader does not yet
  accept multi-release driver jars, and PostgreSQL JDBC 42.7.12, the first release that fixes
  CVE-2026-54291 (GHSA-j92g-9f8w-j867) and CVE-2026-42198 (GHSA-98qh-xjc8-98pq), is one, so a JDBC
  bundle cannot use the fixed driver until that limitation is lifted (#280). The runtime PostgreSQL
  execution store is not affected: it ships 42.7.12.

## Security

- The PostgreSQL shared execution store now ships PostgreSQL JDBC 42.7.12, which fixes a silent
  channel-binding authentication downgrade (GHSA-j92g-9f8w-j867, CVE-2026-54291) and a CPU-exhaustion
  denial of service through unbounded PBKDF2 iterations in SCRAM authentication (GHSA-98qh-xjc8-98pq,
  CVE-2026-42198). Deployments that select the shared store receive the corrected driver without
  configuration changes.

## Features

- Operators can apply durable generation-fenced Pause, Resume, Cancel, Drain, and recoverable Stop
  commands to one process instance and all of its contained traversals without stopping sibling
  processes in the same graph runtime.
- Administrators can inspect a bounded, payload-free Human Task consistency inventory and dry-run or
  apply selector-bounded, idempotent cancellation and forced-abandonment reconciliation through
  storage-agnostic APIs.
- Human Task confirmations can now pin bounded incoming `text/plain` review content for authorized exact-task detail, with durable recovery and summary-only inbox and attention lists.
- Externalize AI agent operational ceilings and publish dynamically sized, atomic skill collections.
- Add schema-defined Human Task settlements, immutable review content, lifecycle-fenced continuation dispatch, and tenant-scoped durable session memory.

## Fixes

- The node catalog now gives Human Task and Log nodes their dedicated visual identities, and saved
  GraphML retains the selected rendering mode and Design arrangement.
