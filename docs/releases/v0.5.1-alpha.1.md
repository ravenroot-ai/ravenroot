# Ravenroot 0.5.1-alpha.1

Ravenroot 0.5.1-alpha.1 delivers the work integrated since `0.5.0-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Fixes

- Managed recovery now discovers only due or resumable durable work, so retained terminal execution history no longer delays human-task and timer continuation after a restart. Existing SQLite and PostgreSQL stores add the supporting indexes automatically during startup.
- Keep IMAP query, mutation, and consumer connections under their cancellation watchdog when a custom socket factory fails; do not retry through an untracked default socket.
- Update the UI test toolchain's locked `undici` dependency to 7.29.1, resolving GHSA-3wwx-pv8p-q78v.
- Release validation now authenticates and preloads the immutable private MinIO fixtures before running the full Maven tests, allowing tagged releases to complete their required checks while keeping the fixture package private.
