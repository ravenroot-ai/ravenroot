# Ravenroot 0.6.0-alpha.1

Ravenroot 0.6.0-alpha.1 delivers the work integrated since `0.5.1-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Features

- The core catalog now includes durable `timer` and data-only `crontab` graph sources with explicit timezones, bounded misfire handling, restart and multi-instance ownership, daylight-saving semantics, and scheduled-versus-actual fire metadata.
- Ravenroot can now retain selected, redacted node inputs and outputs in an optional durable activity archive, with bounded best-effort or strict execution policies, SQLite and PostgreSQL Service storage, and tenant-scoped incremental history reads.
- AMQP and IMAP inbound sources now allow multiple deployment-scoped consumers on the same authorized
  queue or folder by default. Set `resourceMode=exclusive` to retain a process-local singleton guard;
  stable IMAP consumer identities and checkpoints keep their existing ownership and isolation rules.
- Deliver the independently installable compiled UI as a versioned static ZIP and non-root UI-only OCI image, with runtime same-origin API/SSE proxying, independent UI/backend prefixes, verified upstream TLS and protected immutable release provenance. Preserve the complete backend plus UI distribution.

## Documentation

- Add step-by-step full and UI-only Kubernetes installation guides and neutral PostgreSQL, Keycloak, PVC and Gateway examples. Document actual OIDC token flow and separate PostgreSQL execution persistence from local security audit, artifact and credential storage.
