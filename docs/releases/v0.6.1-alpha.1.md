# Ravenroot 0.6.1-alpha.1

Ravenroot 0.6.1-alpha.1 delivers the work integrated since `0.6.0-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Fixes

- Administrators can now admit exact internal network scopes and credential-bearing plaintext connector hops, including authenticated IMAP and every Kafka broker/coordinator connection, for service meshes and TLS-terminating proxies without weakening service grants, DNS rebinding checks, or certificate verification.
