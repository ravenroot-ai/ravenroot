# Ravenroot 0.7.0-alpha.1

Ravenroot 0.7.0-alpha.1 delivers the work integrated since `0.6.1-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Features

- Workbench authors can keep durable personal node palettes, save safely filtered configured nodes, and insert them by click or drag with destination reference checks, terminal safeguards, and one-step undo.
- Ravenroot Workbench now installs versioned frontend layout and declarative renderer packages from the browser, composes compatible providers without rebuilding the core UI, persists drawing-model choices and explicit workflow projections in GraphML, and includes an installable textbook DFA/NFA visual model with sandboxed execution and integrated-renderer fallback.
- Graphs can now call an exact registered graph version with `call-flow`, or split invocation and waiting with `start-flow` and `await-flow`; durable opaque handles, bounded schema-checked payloads, restart-safe caller continuation, explicit terminal outcomes, and creator-bound target authorization keep intergraph execution observable and recoverable.
