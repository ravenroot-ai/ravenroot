# Ravenroot 0.7.0-alpha.1

Ravenroot 0.7.0-alpha.1 delivers the work integrated since `0.6.1-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Features

- Graphs can now coordinate durable sagas across explicit effect participants with persisted forward and compensation state, stable operation and message identities, outcome reconciliation, and atomically recorded outbox intents. SQLite and PostgreSQL persistence, fenced recovery, bounded operator actions, status APIs, and governed JDBC, AMQP, and HTTP adapters keep unknown or exhausted effects visible instead of reporting false completion.
- Workbench authors can keep durable personal node palettes, save safely filtered configured nodes, and insert them by click or drag with destination reference checks, terminal safeguards, and one-step undo.
- Operators can use the standalone visual configurator to create a portable, tenant- and target-bound `.rrcfg` package, review its redacted plan, and apply generated Compose, Kubernetes, Helm, or pre-start configuration without building extension source on the target. Versioned schemas and Java resolver probes validate connector-specific names, origins, headers, secret bindings, and encoded OpenAPI specifications, with the guided UI and package validation enforcing the 2 MiB decoded specification limit.
- Operators can preview and start a fresh selectively derived execution from retained output at one proven acyclic downstream boundary, including a completed parallel-join predecessor closure. The source stays immutable while the new execution receives fresh identities and copied evidence; Ravenroot revalidates settlement and pins, requires an authorized decision for ambiguous source outcomes or future effects, and explicitly refuses mapped, iteration, cycle, direct-join, expired-evidence, or incompatible-runtime boundaries.
- Ravenroot Workbench now installs versioned frontend layout and declarative renderer packages from the browser, composes compatible providers without rebuilding the core UI, persists drawing-model choices and explicit workflow projections in GraphML, and includes an installable textbook DFA/NFA visual model with sandboxed execution and integrated-renderer fallback.
- Graphs can now call an exact registered graph version with `call-flow`, or split invocation and waiting with `start-flow` and `await-flow`; durable opaque handles, bounded schema-checked payloads, restart-safe caller continuation, explicit terminal outcomes, and creator-bound target authorization keep intergraph execution observable and recoverable.
