# Ravenroot 0.8.0-alpha.1

Ravenroot 0.8.0-alpha.1 delivers the work integrated since `0.7.0-alpha.1`. Pin every Maven and OCI
dependency to this exact version, and use an immutable container digest where deployment
reproducibility matters.

## Features

- Ravenroot's workspace and embedded viewer now support validated, live locale catalogs with English
  fallback, persisted language choice, isolated iframe locale updates, and audited coverage of
  product-owned presentation text.
- AMQP nodes now expose Consumer/Subscriber and Producer/Publisher modes. Subscribers receive independent
  online-only topic copies through bounded broker-owned ephemeral queues, while Producers can address an
  authorized queue and Publishers require an operator-authorized existing topic exchange.
- Support GitLab.com and GitLab Self-Managed repository-backed graph authoring, tenant-confined drafts and reviewed merge request proposals, with immutable publication through a GitLab CI example.
- Operators can now opt the complete authenticated Workbench into iframe hosting with validated
  same-origin or CSP-representable HTTP(S) DNS/IPv4 portal ancestors, while embedded-viewer authority
  and plugin sandbox isolation remain independent.

## Fixes

- Embedded servers can now opt into the supported Git graph-authoring and immutable published-artifact composition through the public bootstrap API, with the same provider settings, tenant isolation, credential handling, and lifecycle cleanup as the packaged server.
- The full Ravenroot container build now completes its Workbench localization audit with the required
  server embed source included in the UI build stage.
