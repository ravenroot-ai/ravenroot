# Troubleshooting and runbooks

Move from observable symptoms through bounded diagnosis and action to an explicit verification.

## Reading path

- [Startup and readiness](startup-readiness.md) — Resolve bind, authentication, engine, plugin, and readiness failures before admitting traffic.
- [Graph validation and execution](graph-execution.md) — Diagnose structural refusals, unknown behavior, routing failures, pause, cancellation, and terminal evidence.
- [Events and persistence](events-persistence.md) — Handle cursor gaps, expired results, unavailable stores, recovery, and drain behavior.
- [Authentication and browser access](identity-browser.md) — Correct token, OIDC, origin, host, and SSE revalidation failures without weakening boundaries.
- [AI, artifacts, plugins, and connectors](ai-extensions.md) — Classify unavailable adapters, provider verification outcomes, sandbox refusal, egress, and compatibility faults.
- [Embed access, backup, and recovery](embed-backup.md) — Resolve gate and session failures, then execute verified backup and restoration procedures.

## Authority boundary

Runbooks authorize only the bounded corrective actions stated for their audience. Storage replacement, deployment changes, and credential rotation remain operator operations.
